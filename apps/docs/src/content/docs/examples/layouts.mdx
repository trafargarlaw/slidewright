Every built-in layout, one slide each. Click the deck and use the arrow keys,
or press <kbd>O</kbd> to see every slide at once.

<DemoDeck client:load markdown={deck} />

A slide picks its layout with `layout:` in its frontmatter. The image layouts
read the picture from `image:` and its description from `imageAlt:`. See
[Layouts](/reference/react/#layouts) for what each layout does, and how to add
your own.
