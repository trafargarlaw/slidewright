A deck with its own look. Everything comes from one stylesheet: colours for
the light and dark schemes, a heading font, a layout made with CSS alone, a
slide class, a styled directive and steps that slide up as they appear.

<DemoDeck client:load markdown={deck} />

The stylesheet loads after the default theme, so its rules win without any
extra specificity. See [Styling](/reference/react/#styling) for the theme
properties and the selectors.
