Code blocks with titles, line numbers, highlight stages and diffs. The
"Walk through" slide highlights one line at each step, and its notes change
with the steps: press <kbd>P</kbd> on that slide to see them.

The options go after the language of a code block. See
[Code blocks](/reference/syntax/#code-blocks) for every option.
