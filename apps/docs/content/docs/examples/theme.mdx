One stylesheet gives this deck its look:

- colours for the light and the dark colour schemes
- a font for the headings
- a layout made with CSS only
- a class for one slide
- a style for a directive
- steps that move up as they show.

<ExampleDeck deck="examples/theme/slides.md" css="examples/theme/style.css" />

The stylesheet loads after the default theme, so its rules apply without
more specific selectors. See [Styling](/docs/reference/react#styling) for
the theme properties and the selectors.

To present this deck from a clone of the repository, run this command in
the [`examples` folder](https://github.com/trafargarlaw/slidewright/tree/master/examples):

```sh
bun run dev theme
```

The CLI loads a `style.css` that is next to the deck.
