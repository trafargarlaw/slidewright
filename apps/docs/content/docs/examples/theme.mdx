Everything comes from one stylesheet: colours for the light and dark schemes,
a heading font, a layout made with CSS alone, a slide class, a styled
directive and steps that slide up as they appear.

<ExampleDeck deck="examples/theme/slides.md" css="examples/theme/style.css" />

The stylesheet loads after the default theme, so its rules win without any
extra specificity. See [Styling](/docs/reference/react#styling) for the theme
properties and the selectors.

To present this deck from a clone of the repository, run `bun run dev theme`
in the [`examples` folder](https://github.com/trafargarlaw/react-slides/tree/master/examples).
A `style.css` next to a deck loads automatically.
