This app shows a text area with Markdown, and a `<Deck>` of that Markdown.
Type in the text area: the deck changes, and shows the slide that has the
cursor. The second slide uses a custom layout. The third slide uses a
component for the `:::callout` directive.

To start the app from a clone of the repository, run this command in the
[`examples` folder](https://github.com/trafargarlaw/slidewright/tree/master/examples):

```sh
bun run react
```

See the [`@slidewright/react` reference](/docs/reference/react) for all
the props of `<Deck>`.
