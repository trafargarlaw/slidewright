This deck is four files. `slides.md` names two chapters, and one of the
chapters names a third file. The deck shows the slides of all the files,
in order.

<ExampleDeck
  deck="examples/chapters/slides.md"
  css="examples/chapters/style.css"
/>

A slide with `src` in its frontmatter stands for the slides of that file.
See [Several files](/docs/reference/syntax#several-files) for the rules.

