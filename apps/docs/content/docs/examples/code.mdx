The "Walk through" slide highlights one line at each step. Its notes change
with the steps too: go to that slide and press <kbd>P</kbd> to see them.

<ExampleDeck deck="examples/code/slides.md" />

The options of a code block go after its language. See
[Code blocks](/docs/reference/syntax#code-blocks) for all the options.
