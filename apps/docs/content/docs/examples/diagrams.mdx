Each `mermaid` code block shows as a diagram. The diagram uses the colours
and the font of its slide.

<ExampleDeck
  deck="examples/diagrams/slides.md"
  css="examples/diagrams/style.css"
/>

The project of this deck has the `mermaid` package. Without it, a `mermaid`
code block shows as code.

- [Diagrams](/docs/reference/syntax#diagrams) in the deck syntax tells how
  to write a diagram.
- [Diagrams](/docs/reference/vite#diagrams) in the Vite plugin reference
  tells how to add Mermaid to a project of the CLI.
- [Diagrams](/docs/reference/react#diagrams) in the React reference tells
  how to add Mermaid to a React app, and how to set the size of a diagram.

the [`examples` folder](https://github.com/trafargarlaw/slidewright/tree/master/examples):

```sh
bun run dev diagrams
```
